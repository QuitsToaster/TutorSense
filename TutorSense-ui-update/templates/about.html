About TutorSense

TutorSense is an AI-powered student performance analysis tool designed to identify at-risk students early. Using attendance, homework scores, participation, and exam performance, our prediction model assists teachers in making informed academic interventions.

Built with Python, Flask, Tailwind CSS, Chart.js, and a Random Forest machine learning model.
